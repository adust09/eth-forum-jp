[[glossary/Hegota|ヘゴタ (Hegotá)]]後の[[glossary/Execution-layer|実行レイヤー]]アップグレードのための[[glossary/Devcon|Devcon]]都市名が必要です。

[[glossary/Execution-layer|実行レイヤー]]は[[glossary/Devcon|Devcon]]都市名を使用し、[[glossary/Consensus-Layer|コンセンサス層]]はアップグレードに星の名前を使用しています。参照：[Post-Merge Network Upgrade Naming Schemes](https://ethereum-magicians.org/t/rfc-post-merge-network-upgrade-naming-schemes/11977)

最近のアップグレード名：

-   :owl: シャペラ (Shanghai + Capella)
-   :blowfish: デンクン (Cancun + Deneb)
-   :giraffe: [[glossary/Pectra|ペクトラ]] (Prague + Electra)
-   :zebra: フサカ (Fulu + [[glossary/Osaka|大阪 (Osaka)]])
-   :polar_bear: [[glossary/Glamsterdam|グラムステルダム]] (Gloas + Amsterdam)
-   :red_question_mark: [[glossary/Hegota|ヘゴタ (Hegotá)]] (Heze + ボゴタ)

次の[[glossary/Execution-layer|実行レイヤー]]名は未定です。[[glossary/Devcon|Devcon]]/Devconnectの順序からすると、[Devconnect 2023](https://devconnect.org/istanbul)がイスタンブールで開催されるため、イスタンブールになるはずですが、[[glossary/Constantinople|コンスタンティノープル]]とイスタンブールは既に[[glossary/fork|フォーク]]名として使用されています。

### [[glossary/Execution-layer|実行レイヤー]]名の潜在的な選択肢

| 名前 | 関連性 | 備考 |
| --- | --- | --- |
| Harbiye | Devconnect 2023の主要会場（イスタンブール会議センター）の近隣地域 | イスタンブール全体というよりはDevconnectに特化している |
| Şişli | HarbiyeとDevconnect 2023会場を含む地区 | ASCII形式はSisliとなり、ボゴタがBogotaとなるのと同様 |
| Osmanbey | Harbiyeに最も近い地下鉄駅で、ŞişliのM2線にある | 3音節；ダイアクリティカルマークなし |
| Taksim | Beyoğlu地区のHarbiyeのすぐ南に隣接する地域 | 国際的に最もよく知られている；2音節で、かばん語にしやすい |
| Bangkok | [[glossary/Devcon|Devcon]] 7、2024年11月 | イスタンブールをスキップし、次のDevcon/Devconnect都市へ移行 |

-   これは編集可能なWiki投稿です。潜在的なオプションを追加/更新してください。

アップグレード名はコア開発者によって選ばれます。
