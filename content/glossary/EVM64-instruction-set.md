**EVM64命令セット**

EIP-7937で定義された、Ethereum Virtual Machine (EVM) が64ビット幅のデータに対して演算を行うための命令セット。EIP-8442では、この命令セットのオペコードが追加され、EVMの効率向上を目指します。
