**部分メッセージベースの行トピック (partial message based row topics)**

RowDASが分散型ブロブスペース再構築を実現するために使用するメカニズムです。これにより、すべてのノードが再構築に貢献できるようになり、スーパーノードの負荷が大幅に軽減されます。
