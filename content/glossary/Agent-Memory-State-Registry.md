**エージェントメモリ状態レジストリ (ERC-8337)**

自律エージェントのメモリ状態の検証可能なバージョン管理を可能にするERC-8337で定義されたシステム。メモリの内容自体はオンチェーンに置かず、その状態の進化の検証可能な履歴を管理します。
